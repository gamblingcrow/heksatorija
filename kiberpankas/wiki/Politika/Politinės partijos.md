# Politinės partijos

| Partija | Ką atstovauja |
|---|---|
| Vienybės partija | Stipri centralizuota valdžia, daug įstatymų, mokesčių ir baudų |
| Laisvės partija | Individo teisės, minimalus kišimasis |
| Progresyvioji partija | Socialinis teisingumas ir lygybė |
| Konservatoriai | Tradicinės vertybės |
| Žalioji partija | Aplinka pirmiausia |
| Socialistų partija | Lygus turto paskirstymas |
| Komunistų partija | Viskas priklauso valstybei |
| Nacionalistų partija | Valstybingumo ir tapatybės išlaikymas |
| Darbo partija | Industrija, darbuotojai, korporacijos |
| Kapitolijaus partija | Korporacijų teisės aukščiau žmonių |
| ReBen partija | Religinės bendruomenės |
